# Spotfire IronPython 2.7 교안

Spotfire의 IronPython 2.7 스크립팅 교안입니다.
**프로그래밍을 해 본 적 없어도** 따라올 수 있도록 개념부터 시작하고,
**생성형 AI로 원하는 스크립트를 얻어내는 절차**까지 다룹니다.

---

## 이 교안이 목표로 하는 것

여러분을 파이썬 개발자로 만들려는 것이 **아닙니다.** 실제 목표는 세 가지입니다.

1. **코드를 읽을 수 있게** — 남이 준 스크립트가 뭘 하는지 알아보기
2. **뭐가 가능한지 알게** — "이건 스크립트로 되겠다"를 판단하기
3. **AI에게 제대로 시킬 수 있게** — 원하는 코드를 받아내고, 검증하고, 고치기

3번이 핵심입니다. 코드를 처음부터 손으로 쓰는 것보다,
**AI에게 정확히 요청하고 결과를 검증하는 능력**이 훨씬 실용적입니다.
그러려면 최소한의 어휘와 Spotfire API의 구조를 알아야 합니다. 그게 3~6장이고,
[7장](07-ai-workflow.html)에서 AI 활용 절차를 틀로 정리합니다.

## 예제 선정 기준

"스크립트로 굳이 짤 필요가 없는 것"은 넣지 않았습니다.
다음 두 가지 중 **하나 이상**에 해당하는 것만 골랐습니다.

1. **기본 기능만으로는 하기 어렵거나 불가능한 것**
   예: 모든 필터링 스킴을 한 번에 초기화 · 마킹한 행을 새 데이터 테이블로 스냅샷 ·
   문서 속성 값에 따라 페이지 자체를 숨기기 · 산점도 매트릭스 자동 생성
2. **여러 시각화·여러 페이지에 한 번에 적용할 수 있어서 유용한 것**
   예: 대시보드 전체 데이터 제한 표현식 일괄 적용 · 모든 차트 축 표현식 동시 전환 ·
   모든 페이지의 시각화를 한 번에 이미지로 내보내기

여기에 더해 Spotfire Q&A에서 반복적으로 올라오는 주제(필터 초기화, 마킹 제어,
이미지·데이터 내보내기, 문서 속성 조작, 시각화 순회)를 우선 반영했습니다.

## 예제 코드는 저장소에도 있습니다

모든 예제는 `scripts/` 폴더에 그대로 실행 가능한 `.py` 파일로도 들어 있습니다.
파일 상단 주석에 **필요한 스크립트 매개변수**와 **수정해야 할 지점**을 적어 두었습니다.

```text
scripts/
├── 01-bulk/       8장 예제 (일괄 적용)
├── 02-data/       9장 예제 (데이터·내보내기)
├── 03-ui/        10장 예제 (동적 UI 제어)
└── 04-advanced/  11장 예제 (심화 자동화)
```

이 파일들은 **AI에게 줄 재료**이기도 합니다. 하고 싶은 일과 가장 비슷한 스크립트를
프롬프트에 붙여 넣으면 결과 품질이 크게 올라갑니다 → [7.3 참조](07-ai-workflow.html)

!!! warning "실행 전에 확인하세요"
    스크립트는 **되돌리기(Undo)가 되지 않는 변경**을 만들 수 있습니다.
    특히 데이터 테이블 교체·삭제, 시각화 일괄 변경, 페이지 삭제 계열은 반드시
    **분석 파일 사본**에서 먼저 시험하세요.
    각 예제의 "검증 포인트"에 위험 요소를 적어 두었습니다.

## 버전 정보

- 대상 스크립트 엔진: **IronPython 2.7** (Spotfire Analyst에 내장)
- 문법 기준: **Python 2.7** — Python 3 문법은 동작하지 않습니다
- API 기준: **Spotfire 14.x / 15.x**. 대부분의 예제는 7.x 이후에서도 동작하며,
  버전에 민감한 API는 각 예제의 "검증 포인트"에 표시했습니다

준비가 되었으면 [1장 · IronPython으로 할 수 있는 일](01-what-you-can-do.html)부터 시작하세요.
