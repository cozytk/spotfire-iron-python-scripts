# Spotfire IronPython 2.7 교안

Spotfire의 IronPython 2.7 스크립팅 교안입니다.
**프로그래밍을 해 본 적 없어도** 따라올 수 있도록 개념부터 시작하고,
**생성형 AI로 원하는 스크립트를 얻어내는 절차**까지 다룹니다.

!!! success "예제 21종은 실제 Spotfire에서 검증했습니다"
    예제 1~21이 사용하는 API를 **Spotfire 14.x / IronPython 2.7.12 환경에서 여덟 차례
    실행해 확인**했습니다. 그 과정에서 이 교안 초안의 오류 8건이 나왔고, 전부 고쳤습니다.

    그때 배운 것을 [7장 · 스크립팅의 현실](07-pitfalls.html)에 모아 두었습니다.
    **다른 자료에서 보기 어려운 내용**이니 예제를 쓰기 전에 한 번 읽어 보세요.

    나중에 추가한 **예제 22·23은 Spotfire 공식 문서를 근거로 작성했고 아직 실측하지
    않았습니다.** 둘 다 읽기 전용이라 안전하지만, 해당 절에 그 사실을 표시해 두었습니다.

## 이 교안이 목표로 하는 것

여러분을 파이썬 개발자로 만들려는 것이 **아닙니다.** 실제 목표는 세 가지입니다.

1. **코드를 읽을 수 있게** — 남이 준 스크립트가 뭘 하는지 알아보기
2. **뭐가 가능한지 알게** — "이건 스크립트로 되겠다"를 판단하기
3. **AI에게 제대로 시킬 수 있게** — 원하는 코드를 받아내고, **검증하고**, 고치기

3번에서 진짜 어려운 부분은 요청이 아니라 **검증**입니다.
AI는 그럴듯하지만 존재하지 않는 Spotfire API를 자신 있게 만들어 냅니다.
그걸 걸러 내려면 최소한의 어휘와 API 구조, 그리고 **실제로 뭐가 잘 깨지는지**를 알아야 합니다.

## 예제 선정 기준

"스크립트로 굳이 짤 필요가 없는 것"은 넣지 않았습니다.
다음 두 가지 중 **하나 이상**에 해당하는 것만 골랐습니다.

1. **기본 기능만으로는 하기 어렵거나 불가능한 것**  
   예: 모든 필터링 스킴을 한 번에 초기화 · 마킹한 행을 새 데이터 테이블로 스냅샷 ·
   문서 속성 값에 따라 페이지 자체를 숨기기 · 산점도 매트릭스 자동 생성
2. **여러 시각화·여러 페이지에 한 번에 적용할 수 있어서 유용한 것**  
   예: 대시보드 전체 데이터 제한 표현식 일괄 적용 · 모든 차트 축 표현식 동시 전환 ·
   모든 페이지의 시각화를 한 번에 이미지로 내보내기

여기에 더해 Spotfire Q&A에서 반복적으로 올라오는 주제(필터 초기화, 마킹 제어,
이미지·데이터 내보내기, 문서 속성 조작, 시각화 순회)를 우선 반영했습니다.

## 시작하기 전에 두 가지

**① 문서 속성을 먼저 만드세요.**  
예제 대부분이 결과를 `Document.Properties["ScriptLog"]` 에 씁니다.
그 속성이 없으면 예제가 **마지막 줄에서 실패**합니다.
[9장 맨 앞의 사전 준비 스크립트](09-examples-visuals.html)를 한 번 실행하면 됩니다.

**② 사본에서 시험하세요.**  
Spotfire의 실행 취소는 스크립트 변경을 온전히 되돌리지 못합니다.
특히 위험도 높음 표시가 붙은 예제는 반드시 사본에서요.

```text
scripts/
├── 00_setup_document_properties.py   ← 이걸 먼저
├── 01-visuals/    9장 예제
├── 02-state/     10장 예제
├── 03-data/      11장 예제
└── 04-create/    12장 예제
```

이 파일들은 **AI에게 줄 재료**이기도 합니다. 하고 싶은 일과 가장 비슷한 스크립트를
프롬프트에 붙여 넣으면 결과 품질이 크게 올라갑니다 → [8.3 참조](08-ai-workflow.html)

## 버전 정보

- 대상 스크립트 엔진: **IronPython 2.7** (Spotfire Analyst에 내장)
  — 동작 확인 환경: **IronPython 2.7.12 / .NET Framework 4.8 (64-bit)**
- 문법 기준: **Python 2.7** — f-string 등 Python 3 전용 문법은 동작하지 않습니다
  (단 `print("a")` 는 동작하고, `from __future__ import print_function` 도 사용 가능 → [4.1](04-python-syntax.html))
- API 기준: **Spotfire 14.x / 15.x**
  — 실행 확인은 14.x에서, API 이름·시그니처·폐기 여부 대조는
  [Spotfire 15.0 API 레퍼런스](https://docs.tibco.com/pub/doc_remote/sfire_dev/area/doc/api/tib_sfire-analyst_api/index.aspx)로 했습니다
- 일부 기능은 최소 버전이 있습니다: `Document.ScriptManager` 는 **12.0 이상**(예제 22)

**환경마다 다를 수 있습니다.** 특히 데이터 내보내기(예제 15)는 라이선스 설정에 따라
동작이 갈립니다. 검증 과정과 결과는 저장소의
[`checks/README.md`](https://github.com/cozytk/spotfire-iron-python-scripts/blob/main/checks/README.md)
에 전부 기록해 두었습니다.

준비가 되었으면 [1장 · IronPython으로 할 수 있는 일](01-what-you-can-do.html)부터 시작하세요.
