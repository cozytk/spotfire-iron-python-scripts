# 요청 템플릿

[`00-context.md`](00-context.md) 블록을 먼저 붙여 넣은 뒤, 아래를 복사해서 대괄호만 채우세요.

---

```text
Spotfire IronPython 2.7 스크립트를 작성해 줘.

[하고 싶은 일]
(한 문장으로. 무엇을 / 어디에 / 어떻게 / 언제 실행되는지)
예: "매출분석 페이지의 모든 막대·선 차트 Y축 범위를, 문서 속성 최소/최대 값으로,
     버튼 클릭 시 한 번에 고정하고 싶다"

[대상 범위]
- 페이지: (전체 / 특정 페이지 이름)
- 시각화: (전체 / 막대 차트만 / 특정 제목만)
- 데이터 테이블: (이름)

[입력]
- 문서 속성: (속성 이름과 예상 값)
- 스크립트 매개변수: (이름과 타입)

[실행 환경]
- (Analyst 데스크톱 / Web Player 둘 다 / 상관없음)

[참고: 동작이 검증된 유사 코드]
(여기에 가장 비슷한 예제 스크립트를 통째로 붙여넣기)
```

---

## 마지막 항목이 가장 중요합니다

**검증된 코드를 재료로 주면 AI가 그 API를 모방합니다.**  
이 저장소의 [`scripts/`](../scripts) 폴더가 그 재료입니다. 21개 전부 실제 Spotfire에서
확인한 것이라, 하나만 붙여 넣어도 결과 품질이 크게 달라집니다.

| 하고 싶은 일 | 재료로 쓸 스크립트 |
|--------------|-------------------|
| 여러 시각화의 속성을 한 번에 바꾸기 | `01-visuals/03_unify_legend_and_title.py` |
| 축 표현식·범위를 일괄 변경 | `01-visuals/02_switch_measure_axis.py` |
| 필터를 조작하기 | `02-state/11_reset_selected_column_filters.py` |
| 마킹을 읽거나 설정하기 | `02-state/08_marking_to_document_property.py` |
| 대시보드 상태 초기화 | `02-state/10_reset_dashboard_state.py` |
| 데이터를 읽어 계산하기 | `02-state/09_propagate_marking_by_key.py` |
| 파일로 내보내기 | `03-data/15_export_tables_to_file.py` |
| 시각화·페이지를 새로 만들기 | `04-create/21_scatter_plot_matrix.py` |
| 문서 전체를 조사하기 | `04-create/18_visual_inventory.py` |

## 요청 전에 스스로 확인할 것

한 문장이 안 만들어지면 **AI에게 물어봐도 소용없습니다.** 요구사항이 아직 흐린 겁니다.

| 항목 | 질문 |
|------|------|
| 무엇을 | 어떤 대상을 바꾸나 |
| 어디에 | 범위는 어디까지인가 (전체 페이지? 한 페이지?) |
| 어떻게 | 어떤 값으로. 그 값은 어디서 오나 |
| 언제 | 무엇이 실행시키나 (버튼? 속성 변경?) |
