1. IronPython으로 할 수 있는 일

문법을 배우기 전에 무엇을 얻을 수 있는지 먼저 봅니다. "이런 것도 되는구나"를 알아야, 나중에 필요할 때 "아 이건 스크립트로 되겠다"는 판단이 섭니다.

1.1 한 문장 정의

IronPython 스크립트는 Spotfire에서 마우스로 하는 거의 모든 조작을, 코드로 대신 시키는 것입니다.

마우스로 시각화 속성 대화상자를 열어 축을 바꾸는 것 — 이걸 코드로 쓰면 스크립트입니다. 여기서 두 가지 힘이 나옵니다.

  1. 반복: 마우스로 40번 해야 하는 걸 코드는 한 번에 합니다
  2. 조건: "사용자가 A를 고르면 이렇게, B를 고르면 저렇게"를 자동으로 판단합니다

반대로 말하면, 마우스로도 못 하는 일은 스크립트로도 대체로 못 합니다. 스크립트는 Spotfire를 조종하는 리모컨이지, 새로운 Spotfire를 만드는 도구가 아닙니다.

1.2 할 수 있는 일 — 영역별

시각화 조작

  • 축 표현식 바꾸기 (Sum([매출]) → Avg([수량]))
  • 시각화 유형 바꾸기 (막대 ↔ 선 ↔ 산점도)
  • 범례·제목·마커 크기·색상 설정
  • 데이터 제한 표현식 걸기 ("최근 12개월만 보기")
  • 축 범위·줌 고정하거나 초기화
  • 시각화를 새로 만들고, 페이지에 원하는 위치로 배치하기

페이지·레이아웃

  • 페이지 이동, 추가, 삭제
  • 페이지 숨기기/보이기 (역할별로 다른 화면)
  • 여러 시각화를 격자로 자동 배치 (예: NxN 산점도 매트릭스)

데이터

  • 데이터 테이블 새로고침, 교체, 추가, 삭제
  • 컬럼 값 읽기 (고유값 목록, 최댓값 등)
  • 조건에 맞는 행 찾기
  • 파일·데이터베이스·정보 링크에서 데이터 가져오기

필터와 마킹

  • 필터 초기화 (전체 / 특정 스킴 / 특정 컬럼만)
  • 특정 필터 값 체크·해제
  • 필터 패널에서 원하는 필터만 보이기
  • 마킹된 행 읽어오기
  • 코드로 마킹하기, 마킹 해제하기
  • 한 테이블의 마킹을 다른 테이블로 전파

문서 속성 (UI와의 다리)

  • 드롭다운·입력 상자 값 읽기
  • 계산 결과를 속성에 써서 화면에 표시
  • 속성 값에 따라 대시보드 동작을 분기

내보내기

  • 시각화를 이미지 파일로
  • 데이터를 Excel·CSV 파일로
  • 분석 파일을 라이브러리에 저장

그 밖에

  • 북마크 목록을 읽고 적용해 상태를 통째로 되돌리기
  • 지도(Map Chart) 레이어 표시/숨김, 특정 위치로 확대
  • 문서 자체의 스크립트 목록을 조사·정리 (Spotfire 12.0 이상)
  • 웹 서비스 호출, 메일 발송 같은 외부 연동 (Analyst 전용인 것이 많음)
  • 그래픽 표·KPI 차트에서 항목을 클릭했을 때 반응하기

무엇이 가능한지 더 넓게 보려면 Spotfire Community의 IronPython 예제 색인을 훑어보세요. 데이터·시각화·필터/마킹·레이아웃·지도·문서·연동으로 분류된 수백 개의 예제 링크가 있습니다. "이런 것도 되는구나"를 늘리는 데는 이만한 자료가 없습니다.

1.3 할 수 없는 일 (또는 하면 안 되는 일)

못 하는 것 이유 대안
pandas, numpy, scikit-learn 사용 IronPython은 C 확장 모듈을 못 읽음 Python 데이터 함수 (1.4)
통계 모델링, 머신러닝 위와 같음 Python/R 데이터 함수
새로운 차트 종류 만들기 Spotfire가 제공하는 유형만 가능 Spotfire Mods, C# 확장 (아래 참조)
Spotfire의 코어 동작 자체를 바꾸기 스크립트는 격리 실행되는 자동화 도구 C# 확장
외부 파이썬 패키지 설치 표준 IronPython 배포 외 모듈 적재가 사실상 불가 데이터 함수, C# 확장
접근 권한 제어 스크립트는 보안 장치가 아님 라이브러리 권한, 정보 링크
브라우저에서 로컬 파일 쓰기 Web Player 제약 라이브러리 저장
마킹 변경 시 자동 실행 직접적인 이벤트 훅 없음 버튼, 문서 속성 트리거
스크립트 중간 결과를 화면에 표시 스크립트 전체가 하나의 트랜잭션 ProgressService(단 실행 취소 포기)
바꾼 결과를 같은 스크립트에서 다시 읽기 위와 같음 스크립트를 둘로 나누고 속성 트리거로 연결

뒤의 두 줄은 처음 보면 이해가 안 되는 제약입니다. 7.4 · 스크립트는 트랜잭션 안에서 통째로 실행된다에서 자세히 다룹니다.

스크립트와 C# 확장의 경계선

공식 문서는 스크립트를 "Spotfire를 자동화하는 것" 으로 못 박습니다. 스크립트는 나머지 Spotfire 코드와 격리되어 실행되고(그래서 잘못된 스크립트가 클라이언트를 죽이지 못합니다), 코어 기능 자체는 바꿀 수 없습니다.

경계선이 가장 뚜렷하게 보이는 예가 커스텀 시각화입니다. Spotfire에는 시각화를 새로 만들기 위한 CustomVisualView 라는 API가 있습니다. Spotfire.Dxp.Application.Extension 네임스페이스의 추상 클래스로, 대략 이런 멤버를 가집니다.

멤버 하는 일
IsEditing 지금 Spotfire UI가 편집 모드인지 (축 선택기 같은 작성용 컨트롤을 이때만 노출)
IsStatic 인쇄·내보내기·미리보기용 정적 뷰인지 (애니메이션을 꺼야 하는 상황)
Invalidate() 뷰를 무효화해 다시 그리게 함
AddEventHandler(...) 트리거가 발생할 때 호출될 핸들러 등록
InvokeClientEventHandler(...) Spotfire.addEventHandler(...) 로 등록해 둔 JavaScript 함수 호출
OnUpdateRequiredCore() 오버라이드해서 HTML/JS 쪽 UI를 다시 렌더링시킴

중요한 건 이름이 아니라 이 클래스를 IronPython에서 쓸 수 없다는 사실입니다. CustomVisualView는 상속해서 구현하는 클래스라, Visual Studio에서 C# 확장(add-in)을 빌드해 배포해야만 의미가 있습니다. 스크립트는 이미 존재하는 시각화를 설정할 뿐, 새로운 시각화 종류를 만들지 못합니다.

판단 기준 한 줄

"UI에서 마우스로 할 수 있는 일" 이면 IronPython으로 됩니다. "UI에 그런 기능 자체가 없는 일" 이면 Mods나 C# 확장 영역입니다. → 스크립팅과 C# 확장 중 무엇을 고를까 (Spotfire Community)

1.4 Python 데이터 함수와 무엇이 다른가

Spotfire에서 "Python"이라고 하면 완전히 다른 두 가지를 가리킵니다. 이걸 헷갈리면 "왜 pandas가 안 되지?"에서 몇 시간을 낭비합니다.

한눈에 비교

IronPython 스크립트 Python 데이터 함수
파이썬 버전 IronPython 2.7 CPython 3.x
실행되는 곳 Spotfire 클라이언트 내부 (.NET 위) 별도 파이썬 프로세스
다루는 대상 문서·시각화·필터·마킹·페이지 데이터 테이블(표) 값
입력 문서 객체, 스크립트 매개변수 데이터 테이블, 컬럼, 문서 속성
출력 문서 상태 변경 (부수 효과) 새 데이터 테이블·컬럼·값
pandas/numpy 불가 가능
시각화 조작 가능 불가
실행 시점 버튼 클릭, 속성 변경 시 데이터가 갱신될 때 자동
설치 Spotfire에 내장 별도 Python 환경 필요

왜 이렇게 나뉘어 있나

IronPython은 .NET 위에서 도는 파이썬입니다. 그래서 .NET으로 만들어진 Spotfire의 내부 객체를 직접 만질 수 있습니다. 대신 pandas 같은 라이브러리는 C로 짜여 있어서 .NET 위에서 로드할 수 없습니다.

Python 데이터 함수는 진짜 파이썬(CPython) 을 별도 프로세스로 띄웁니다. 그래서 pandas가 되지만, 그 프로세스는 Spotfire의 화면을 볼 수 없습니다. 데이터만 주고받습니다.

판단 기준

화면을 바꾸고 싶다 → IronPython 숫자를 계산하고 싶다 → Python 데이터 함수

하고 싶은 일 어느 쪽
버튼 누르면 모든 차트 축이 바뀌게 IronPython
필터를 한 번에 초기화 IronPython
마킹한 행을 새 테이블로 저장 IronPython
이미지로 내보내기 IronPython
회귀분석해서 예측값 컬럼 추가 Python 데이터 함수
이상치 탐지 알고리즘 적용 Python 데이터 함수
텍스트에서 키워드 추출 Python 데이터 함수
시계열 예측 Python 데이터 함수

둘을 같이 쓰기

실무에서는 조합해서 씁니다.

① Python 데이터 함수: 이상치 점수를 계산해 새 컬럼 생성
                  ↓
② IronPython 스크립트: 점수가 높은 행을 자동으로 마킹하고,
                     그 행만 보는 차트를 새 페이지에 생성

계산은 데이터 함수가, 그 결과를 화면에 어떻게 보여 줄지는 IronPython이 담당합니다.

R, TERR은 어디에 해당하나

TERR(TIBCO Enterprise Runtime for R)이나 R 데이터 함수도 데이터 함수 쪽입니다. 계산 담당이고, 화면은 못 건드립니다. 판단 기준은 위와 같습니다.

1.5 이 교안이 목표로 하는 것

이 교안은 여러분을 파이썬 개발자로 만들려는 것이 아닙니다.

실제 목표는 이것입니다.

  1. 코드를 읽을 수 있게 — 남이 준 스크립트가 뭘 하는지 알아보기
  2. 뭐가 가능한지 알게 — "이건 스크립트로 되겠다"를 판단하기
  3. 생성형 AI에게 제대로 시킬 수 있게 — 원하는 코드를 얻어내고, 검증하고, 고치기

3번이 핵심입니다. 요즘은 코드를 처음부터 손으로 쓰는 것보다, AI에게 정확히 요청하고 결과를 검증하는 능력이 훨씬 실용적입니다. 그런데 그러려면 최소한의 어휘(변수, 객체, 속성, 메서드…)와 Spotfire API의 구조를 알아야 합니다. 그래서 3~6장에서 그걸 다루고, 7장에서 실제로 부딪히는 함정을 정리한 뒤, 8장에서 AI 활용 절차를 틀로 만들어 제시합니다.

다음 장에서는 스크립트를 실제로 어디에 넣고 실행하는지부터 봅니다.
