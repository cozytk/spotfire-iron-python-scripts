Spotfire IronPython 2.7 교안

Spotfire의 IronPython 2.7 스크립팅 교안입니다. 프로그래밍을 해 본 적 없어도 따라올 수 있도록 개념부터 시작하고, 생성형 AI로 원하는 스크립트를 얻어내는 절차까지 다룹니다.

예제 21종은 실제 Spotfire에서 검증했습니다

모든 예제가 사용하는 API를 Spotfire 14.x / IronPython 2.7.12 환경에서 여덟 차례 실행해 확인했습니다. 그 과정에서 이 교안 초안의 오류 8건이 나왔고, 전부 고쳤습니다.

그때 배운 것을 7장 · 스크립팅의 현실에 모아 두었습니다. 다른 자료에서 보기 어려운 내용이니 예제를 쓰기 전에 한 번 읽어 보세요.

이 교안이 목표로 하는 것

여러분을 파이썬 개발자로 만들려는 것이 아닙니다. 실제 목표는 세 가지입니다.

  1. 코드를 읽을 수 있게 — 남이 준 스크립트가 뭘 하는지 알아보기
  2. 뭐가 가능한지 알게 — "이건 스크립트로 되겠다"를 판단하기
  3. AI에게 제대로 시킬 수 있게 — 원하는 코드를 받아내고, 검증하고, 고치기

3번에서 진짜 어려운 부분은 요청이 아니라 검증입니다. AI는 그럴듯하지만 존재하지 않는 Spotfire API를 자신 있게 만들어 냅니다. 그걸 걸러 내려면 최소한의 어휘와 API 구조, 그리고 실제로 뭐가 잘 깨지는지를 알아야 합니다.

읽는 순서

1~2장 · 시작하기

IronPython으로 가능한 일과 불가능한 일, Python 데이터 함수와의 차이, 스크립트를 어디에 넣고 어떻게 실행하는지.

3~5장 · 언어

프로그래밍 기초 개념(변수·객체·속성·메서드), Python 2.7 문법, IronPython 특유의 As[T]()·clr.

6장 · API 객체 모델

Document에서 시작해 페이지·시각화·데이터·마킹·필터로 내려가는 지도.

7장 · 스크립팅의 현실

실제로 부딪힌 함정 모음. 이름이 환경마다 다른 문제, 조용히 None을 반환하는 API, 존재하지 않는 API, 확인하는 다섯 가지 방법.

8장 · 생성형 AI 활용법

목표 정의 → 재료 제공 → 요청 → 검증 → 수정. 프롬프트 템플릿과 실행 전 체크리스트.

9~12장 · 예제 21선

예제마다 위험도 배지가 붙습니다. 문제 상황, 코드, 매개변수 설정, 실행 전 확인 사항.

13~14장 · 레퍼런스

성능·멱등성·보안, 자주 쓰는 API 한 장 요약과 FAQ.

이미 프로그래밍을 아신다면

1장 → 2장 → 4.1(Python 3와 다른 점) → 5장 → 6장 → 7장 → 8장 순으로 보세요. 3장은 건너뛰어도 됩니다. 7장은 건너뛰지 마세요.

12장 · 문서 생성과 진단

문서에 없던 것을 만들거나, 문서 전체를 조사합니다. 진단 예제는 위험한 작업 전에 현재 상태를 기록해 두는 용도로 쓰세요.

# 예제 위험도
18 문서 전체 시각화 인벤토리 만들기 읽기 전용

21 산점도 매트릭스 자동 생성 (NxN) 높음

예제 선정 기준

"스크립트로 굳이 짤 필요가 없는 것"은 넣지 않았습니다. 다음 두 가지 중 하나 이상에 해당하는 것만 골랐습니다.

  1. 기본 기능만으로는 하기 어렵거나 불가능한 것
    예: 모든 필터링 스킴을 한 번에 초기화 · 마킹한 행을 새 데이터 테이블로 스냅샷 · 문서 속성 값에 따라 페이지 자체를 숨기기 · 산점도 매트릭스 자동 생성
  2. 여러 시각화·여러 페이지에 한 번에 적용할 수 있어서 유용한 것
    예: 대시보드 전체 데이터 제한 표현식 일괄 적용 · 모든 차트 축 표현식 동시 전환 · 모든 페이지의 시각화를 한 번에 이미지로 내보내기

여기에 더해 Spotfire Q&A에서 반복적으로 올라오는 주제(필터 초기화, 마킹 제어, 이미지·데이터 내보내기, 문서 속성 조작, 시각화 순회)를 우선 반영했습니다.

시작하기 전에 두 가지

① 문서 속성을 먼저 만드세요.
예제 대부분이 결과를 Document.Properties["ScriptLog"] 에 씁니다. 그 속성이 없으면 예제가 마지막 줄에서 실패합니다. 9장 맨 앞의 사전 준비 스크립트를 한 번 실행하면 됩니다.

② 사본에서 시험하세요.
Spotfire의 실행 취소는 스크립트 변경을 온전히 되돌리지 못합니다. 특히 위험도 높음 표시가 붙은 예제는 반드시 사본에서요.

scripts/
├── 00_setup_document_properties.py   ← 이걸 먼저
├── 01-visuals/    9장 예제
├── 02-state/     10장 예제
├── 03-data/      11장 예제
└── 04-create/    12장 예제

이 파일들은 AI에게 줄 재료이기도 합니다. 하고 싶은 일과 가장 비슷한 스크립트를 프롬프트에 붙여 넣으면 결과 품질이 크게 올라갑니다 → 8.3 참조

버전 정보

  • 대상 스크립트 엔진: IronPython 2.7 (Spotfire Analyst에 내장) — 동작 확인 환경: IronPython 2.7.12 / .NET Framework 4.8 (64-bit)
  • 문법 기준: Python 2.7 — f-string 등 Python 3 전용 문법은 동작하지 않습니다 (단 print("a") 는 동작하고, from __future__ import print_function 도 사용 가능 → 4.1)
  • API 기준: Spotfire 14.x / 15.x

환경마다 다를 수 있습니다. 특히 데이터 내보내기(예제 15)는 라이선스 설정에 따라 동작이 갈립니다. 검증 과정과 결과는 저장소의 checks/README.md 에 전부 기록해 두었습니다.

준비가 되었으면 1장 · IronPython으로 할 수 있는 일부터 시작하세요.
