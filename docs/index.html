Spotfire IronPython 2.7 교안

Spotfire의 IronPython 2.7 스크립팅을 문법부터 실전 예제까지 순서대로 익히는 교안입니다. 읽는 순서대로 따라가면 되고, 필요한 부분만 골라 봐도 됩니다.

이 교안의 구성

교안은 크게 두 덩어리입니다. 앞부분(1~4장)에서 문법과 API 구조를 먼저 훑고, 뒷부분(5~8장)에서 예제를 봅니다.

1장 · 스크립트 실행 환경

어디에 스크립트를 넣고, 어떻게 실행하고, 어떻게 디버깅하는지. 스크립트 매개변수 개념까지.

2장 · IronPython 2.7 문법

Python 2.7 문법 전반. 특히 Python 3에 익숙한 사람이 반드시 걸리는 차이점들.

3장 · .NET 상호운용 문법

clr, 제네릭 As[T](), .NET 타입/배열/열거형 등 IronPython만의 문법.

4장 · Spotfire API 객체 모델

Document에서 시작해 페이지·시각화·데이터·마킹·필터로 내려가는 지도.

5~8장 · 예제 18선

실제로 유용한 스크립트만. 각 예제마다 문제 상황, 코드, 매개변수 설정, 검증 포인트를 함께 제공합니다.

9~10장 · 실무 팁과 치트시트

성능·오류처리·Web Player 호환성, 그리고 자주 쓰는 API 한 장 요약과 FAQ.

예제 선정 기준

이 교안의 예제는 "스크립트로 굳이 짤 필요가 없는 것"은 넣지 않았습니다. 다음 두 가지 중 하나 이상에 해당하는 것만 골랐습니다.

  1. 기본 기능만으로는 하기 어렵거나 불가능한 것 예) 모든 필터링 스킴을 한 번에 초기화, 마킹한 행을 새 데이터 테이블로 스냅샷, 문서 속성 값에 따라 페이지 자체를 숨기기
  2. 여러 시각화·여러 페이지에 한 번에 적용할 수 있어서 유용한 것 예) 대시보드 전체 시각화의 데이터 제한 표현식 일괄 적용, 모든 차트의 축 표현식 동시 전환, 모든 페이지의 시각화를 한 번에 이미지로 내보내기

각 예제 제목 옆에 다음 배지로 성격을 표시했습니다.

  • 기본 기능으로 어려움
  • 일괄 적용
  • 자주 묻는 질문

자주 묻는 질문 배지는 Spotfire 커뮤니티와 각종 Q&A에서 반복적으로 올라오는 주제를 뜻합니다. 필터 초기화, 마킹 제어, 이미지/데이터 내보내기, 문서 속성 조작, 시각화 순회가 특히 자주 나옵니다.

18 표현식 전수 검사(문서 감사 리포트) 8장 기본 기능으로 어려움

예제 코드는 저장소에도 있습니다

모든 예제는 scripts/ 폴더에 그대로 실행 가능한 .py 파일로도 들어 있습니다. 파일 상단 주석에 필요한 스크립트 매개변수와 수정해야 할 지점을 적어 두었습니다.

scripts/
├── 01-bulk/       5장 예제 (일괄 적용)
├── 02-data/       6장 예제 (데이터·내보내기)
├── 03-ui/         7장 예제 (동적 UI 제어)
└── 04-advanced/   8장 예제 (심화 자동화)

실행 전에 확인하세요

스크립트는 되돌리기(Undo)가 되지 않는 변경을 만들 수 있습니다. 특히 데이터 테이블 교체·삭제, 시각화 일괄 변경 계열은 반드시 분석 파일 사본에서 먼저 시험하세요. 각 예제의 "검증 포인트"에 위험 요소를 적어 두었습니다.

버전 정보

  • 대상 스크립트 엔진: IronPython 2.7 (Spotfire Analyst에 내장)
  • 문법 기준: Python 2.7 — Python 3 문법은 동작하지 않습니다
  • API 기준: Spotfire 14.x / 15.x 기준으로 작성했으며, 대부분의 예제는 7.x 이후 버전에서도 동작합니다. 버전에 민감한 API는 각 예제의 "검증 포인트"에 따로 표시했습니다.

준비가 되었으면 1장 · 스크립트 실행 환경부터 시작하세요.
