# 예제 23종

**1~21은 전부 실제 Spotfire에서 확인**했습니다.
**22·23은 공식 문서를 근거로 작성했고 아직 실행 검증을 하지 않았습니다**(둘 다 읽기 전용).
**요청과 가장 비슷한 것을 골라 구조와 API 사용 방식을 따르세요.**

전문: <https://cozytk.github.io/spotfire-iron-python-scripts/>
코드: 저장소 `scripts/` 폴더

| 3 | 범례·제목·서식 일괄 통일 | 낮음 | `Legend.Visible`, `MarkerSize` |

## 위험한 작업 전에

18(인벤토리)·19(표현식 감사)·22(스크립트 조사)·23(환경 진단)은 **읽기 전용**입니다.
7·20·21처럼 되돌릴 수 없는 작업을 하기 전에 **현재 상태를 기록해 두는 용도**로
먼저 실행하도록 안내하세요.

특히 사용자가 "왜 이 스크립트가 안 되지"라고 물으면 **23번을 먼저 돌려 보게** 하세요.
클라이언트 종류·마킹 이름·내보내기 라이선스가 원인인 경우가 대부분입니다.
